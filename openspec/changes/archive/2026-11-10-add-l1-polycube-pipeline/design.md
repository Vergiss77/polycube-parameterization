# Design

## Context

- 仓库目前只有两篇论文、`models/` 下三个 OFF 模型和 OpenSpec 配置，没有任何代码。动机见 proposal.md。
- 三个模型的实测特征（决定了默认参数和风险点）：

  | 模型 | V / F | 亏格 | 包围盒 | 已轴对齐面积 | 特点 |
  |---|---|---|---|---|---|
  | I-SPAR | 14767 / 29530 | 0 | 320×70×100 | 100% | 本身就是 polycube，翼缘薄（9） |
  | CLEVIS | 20840 / 41684 | 2 | 95×55×65 | 97% | 两个沿 Y 的销孔，r=7 |
  | TAILSITTER | 28326 / 56668 | 5 | 87.5×87.5×8 | 48.6% | 圆环加 4 根 45° 斜臂；臂比环薄 1（上下各下沉 0.5） |

  三者都是闭合 2-流形，最小内角 ≥13°，网格各向同性。
- 必须能在 Windows（MSVC）和 macOS（Apple clang）上构建；只用于研究，接受 TetGen 的 AGPL 许可证。
- 后续 change 会在本 change 的输出上做 Chen 2019 的高度简化（需要按给定面片高度重新求映射），以及分块和样条拟合（需要 polycube 到原空间的点查询）。本设计要为这两者预留接口。

## Goals / Non-Goals

**Goals:**
- 完整实现 Huang 2014 的 ℓ1 polycube 求解器：能量项、全局旋转、调度、SQP-Schur 求解、log barrier。
- 每个能量项都有可单独测试的数值、梯度和半正定 Hessian，并通过有限差分检查。
- 最终映射模块同时支持"高度自由"（本 change 用）和"高度固定"（Chen 用）两种模式。
- 单线程、确定性实现，先保证正确，再优化性能。

**Non-Goals:**
- 不做细长三角形塌缩或自适应重网格化，只检测并记录日志。
- 不做 Chen 的有向图简化、分块、B 样条（后续 change）。
- 不做并行化与性能极限优化（只做分解结构复用这一项必要优化）。
- 不做交互式特征边选择 UI；特征边只能通过文件输入。

## Decisions

### D1 工程结构
```
CMakeLists.txt
cmake/            # FetchContent 依赖配方、编译选项
src/pcp/          # 核心静态库 pcp（命名空间 pcp）
  io/             # OFF 读写、校验、vtu/tmsh 导出
  tet/            # TetGen 封装
  geom/           # 梯度算子、法向/面积及其导数、极分解
  polycube/       # 能量项、SQP 求解器、旋转、调度
  structure/      # 标号、清理、面片图、最终映射、点查询
apps/pcp_cli/     # 命令行工具
apps/pcp_view/    # 可选 polyscope 查看器（PCP_BUILD_VIEWER，默认 OFF）
tests/            # doctest 单元测试 + 模型集成测试
```
核心库不依赖 CLI 和查看器，后续 change 直接往 `src/pcp/` 里加模块。

### D2 依赖（全部 FetchContent，锁定 tag 或 commit）
| 依赖 | 用途 | 说明 |
|---|---|---|
| libigl（锁定一个正式 release） | 极分解辅助、TetGen 封装（`igl::copyleft::tetgen`）、AABB 点定位 | 打开 copyleft/tetgen 模块 |
| Eigen | 线性代数、稀疏 LDLT | **使用 libigl 配方锁定的版本（预期 3.4.x）**，不单独引入 Eigen 5，避免版本冲突 |
| TetGen | 四面体化 | 由 libigl 配方获取 |
| nlohmann/json | 参数文件、面片图、统计报告 | 仅头文件 |
| CLI11 | 命令行解析 | 仅头文件 |
| doctest | 测试 | 仅头文件 |
| polyscope | 可选查看器 | 默认关闭 |

备选方案：自己写 JSON 和参数解析可以少两个依赖，但这两个库都只有头文件、跨平台成熟，代码量收益更大。fTetWild 更健壮但更重，用户已确认 TetGen 可接受。

### D2b 四面体化后的边分裂（实现中补充）
TetGen 输出后，把所有"两端都在边界上的内部边"从中点分裂（新点都在内部，边界三角形不变）。否则会出现两类必然的翻转：4 个顶点都在同一个面片上的四面体，被压平后体积为零；跨在凹棱两侧、却不含棱边的四面体，棱形成时被撕翻。实测 CLEVIS 在不分裂时，最终映射有 8 个翻转四面体（3 个零体积，5 个跨棱），且与初值、收敛容差都无关。代价是节点数增加约 7%~38%（I-SPAR 的薄翼缘最多）。参数 `tet.split_boundary_edges` 可以关闭。

### D3 尺度归一化
优化前把模型平移到质心，并整体缩放到**边界总面积 = 1**，输出时再逆变换回去。这样 ε、阈值 1e-3、α 调度对 I-SPAR（长 320）和 TAILSITTER（长 87）有相同含义。
与论文的差异：论文的 E1 没有按面积归一化；这里 E1 除以边界总面积（缩放后恒为 1），所以 α 的含义和论文一致。

### D4 能量项接口
每个能量项实现 `value(X)`、`gradient(X)`，以及把半正定 Hessian 近似写入**预先确定的稀疏模式**的函数。
- **E1（ℓ1）**：设 a = 面积向量 = ½(e1×e2) = A·n，那么 A|n_c| = |a_c|。光滑形式取 `sqrt(a_c² + ε·Ā²)`，其中 Ā 是本轮开始时的三角形面积（滞后量），这样等价于论文的 A·sqrt(n_c²+ε)，而 a_c 是 X 的二次函数。Hessian 为 `ε·Ā²/ã³ ∇a∇aᵀ + (a/ã)∇²a`，第二项对每个三角形的 9×9 常矩阵做特征值截断（负特征值置零）。
- **Eδ（ARAP）**：每个四面体的梯度算子 Gᵢ（3×4）在静止形状上预计算。梯度为 GᵀGX − Gᵀpolar(GX)，Hessian 为常矩阵 GᵀG，按 V/ΣV 加权。极分解用 3×3 SVD，并修正反射。
- **Eη（β 复杂度）**：按论文式 (8)–(10)，权重 A(e_ij) 每轮滞后更新。默认 β = 0.1（实现中修订，原为 1）：Eη 同样惩罚输入中已有的 90° 棱，β=1 时 CLEVIS 的所有棱从第一阶段起就被磨圆，此后再也无法恢复成直角，误差卡在 0.01。β=0 或 0.1 时，88~117 次迭代即可收敛到 6e-4 以下。Hessian 用 Gauss-Newton 近似 JᵀJ，J 是单位法向差对 6 个顶点（两三角形共享 2 个，所以实际 4 个）的雅可比。
- **Ee（特征边）**：ω(nᵢ·nⱼ)² 或 ω(nᵢ·nⱼ−1)²，同样用 Gauss-Newton。
- **Barrier**：−μ Σ log(nᵢ·nⱼ + 1)，求和遍历相邻边界三角形对，Hessian 用 Gauss-Newton。

所有项的稀疏模式取并集，即四面体节点邻接加上相邻边界三角形对的 4 个顶点，**初始化时一次性确定**。

### D5 SQP 步与线性求解
- KKT 系统按论文式 (15)/(16) 用 Schur 补求解：一次分解 H，两次回代（右端分别为 g 和 ∇C）。
- H 有平移零空间（ARAP 和 ℓ1 都对平移不变），因此求解 `H + μ·M`，M 是集中质量矩阵（对角），μ 取 H 对角线均值的很小比例。这同时起到 Levenberg-Marquardt 阻尼的作用：步长失败时增大 μ，成功时减小。
  备选：固定一个节点，但会在该点附近引入人为畸变，所以不采用。
- 线性求解（实现中修订）：未知数不超过 3 万时用 `Eigen::SimplicialLDLT`（AMD 排序，`analyzePattern` 只做一次）；更大时改用**不完全 Cholesky 预条件的共轭梯度**做非精确求解（相对残差默认 1e-4，即截断 Newton），两次回代共用同一个预条件子。
  原因：实测 CLEVIS（10.6 万未知数）的 L 因子有 8000 万个非零元（原矩阵的 16 倍），单次分解 23 秒；IC-CG 每次迭代约 2 秒，且不引入新依赖、结果确定。参数 `linear_solver = auto | direct | cg` 可强制选择。
  每次 CG 求解的迭代上限默认 100（`cg_max_iterations`）：后期阶段（ε ≤ 0.03）ℓ1 项使 Hessian 极度病态，CG 基本无法达到容差。由于从零出发的 CG 迭代对正定系统总是下降方向，提前截断仍然安全。球体实测：上限 3000 时 665 秒，上限 100 时 43 秒，外层迭代数与最终误差相当。
- 线搜索：回溯法，merit = 总能量 + ρ|C(X)|。步长必须保持所有 barrier 项可行，也就是 nᵢ·nⱼ > −1。
- 如果连续若干步步长小于阈值，且梯度仍然较大，判定为 barrier 停滞：记录事件及夹角小于 5° 的边界三角形数，然后结束本阶段。

### D6 全局旋转
**开始前先做一次粗搜索（实现中补充）**：在立方体对称群的基本区域（ZYX 欧拉角 [0°,90°)³，默认步长 6°）上用精确 ℓ1 代价逐个评估候选旋转，取最优者再局部细化，最后在 24 个等价旋转中取最接近单位矩阵的那个。原因：TAILSITTER 的臂正好在 45°，圆环和凸台又旋转对称，单位旋转是一个梯度为零的对称驻点，纯局部优化转不动。代价比较时并列取更接近单位矩阵者，因此已对齐的模型（I-SPAR、CLEVIS）保持不转。

之后每次 SQP 迭代仍按论文做局部更新。不用论文的"3×3 矩阵加正交罚项"，改为用轴角参数化：R = exp([ω]×)·R₀，只对 3 个参数优化平滑 ℓ1 目标（带数值梯度的 BFGS，或 Gauss-Newton），每个 SQP 外循环前做几步。求出的增量旋转绕质心作用到当前 X 上，并累积总旋转用于报告。ARAP 能量对旋转不变，所以不需要改动静止形状。
理由：结果一定是正交矩阵，变量更少，也省掉了投影回旋转矩阵那一步。

### D7 调度与收敛
默认值取自 Huang：α₀=0.1、ε₀=1；每阶段 α×2，ε 在大于 0.01 时减半。阶段结束条件：最近 5 步 |Δd| 之和 < d₀/100，或步长收敛，或达到单阶段迭代上限（默认 50，作为保险）。整体在 d < 1e-3 或 20 个阶段后停止。**开始前先检查一次**：初始误差已低于阈值时不做变形（I-SPAR 即此情形；否则 d₀≈0 会使"误差停止下降"判据永远不成立）。全部参数都可配置。

### D8 标号与结构提取
- 先按旋转后的法向给出初始标号，再迭代清理锯齿；之后用"标号相同且边相连"求连通分量得到面片，计算每个面片的度，按论文规则迭代合并度为 1、2 的面片，直到稳定。
- 棱边 = 两侧面片不同的边。三个及以上面片交汇的顶点是角点；角点之间的棱边链是棱线，棱线的平行轴由两侧面片轴向之外的第三个轴确定。
- 拓扑检查失败（相邻面片同轴，或欧拉示性数改变）时报告并终止，不输出结构。
- 面片图输出为 JSON。棱线记录"平行轴 + 两端所连的同轴面片"，这正是 Chen 构造有向边需要的数据。

### D9 最终映射（带线性约束的 ARAP）
- 逐坐标轴 k 做变量替换：若节点 i 属于某个轴向为 k 的面片 p，它的 k 坐标就由 h_p 代替；否则是自由变量。如果同一节点属于两个同轴面片（只在角点处接触的退化情形），用并查集把两个高度合并。
- local-global 迭代：global 步是三个独立的约化最小二乘问题，三个矩阵都是常数，各分解一次。
- 初值按 Huang 式 (17) 做 Laplacian 松弛，同样在约化变量上求解。高度初值取 ℓ1 结果中面片节点轴向坐标的面积加权平均。
- 提供 `heights_fixed` 模式：h_p 作为已知量移到右端项，供 Chen 简化后复用。
- 输出每个四面体的 ARAP 畸变和翻转四面体数。

### D10 点查询
在最终 polycube 四面体网格上建 AABB，查询时返回所在四面体编号和重心坐标，再用原坐标插值；找不到时返回空值。后续分块采样直接使用这个接口。

### D11 文件与输出
- 中间结果存为自定义文本格式 `.tmsh`（节点用 `%.17g`，加四面体和边界映射），保证续跑时逐位一致。不用 MEDIT `.mesh`，是因为不确定 libigl 的写出精度。
- 输出目录：
  ```
  <out>/params.json  stats.json  log.txt
  00_validate.json
  01_tet.tmsh  01_tet.vtu
  02_l1.tmsh   02_l1.vtu            (逐四面体 ARAP 畸变)
  03_labels_input.vtu  03_labels_polycube.vtu  03_patch_graph.json
  04_polycube.tmsh  04_polycube.vtu (最终映射, 逐四面体畸变)
  ```
- `.vtu` 自己写 ASCII XML 格式，不依赖 VTK 库。

### D12 跨平台约定
C++17；路径一律用 `std::filesystem`；文本文件用二进制模式写，统一 `\n` 换行；数值输出不受 locale 影响；不用 `M_PI`，改用自定义常量；索引用 `int` / `int64_t` / `Eigen::Index`，不用 `long`；MSVC 加 `/bigobj /permissive- /utf-8`；Apple clang 和 MSVC 都开警告。不使用随机数，也不使用依赖线程调度的归约。

### D13 测试策略
- 单元测试：OFF 读写和错误处理；在立方体、环面、带边界的小网格上测校验；每个能量项做**有限差分梯度检查**，并检查 Hessian 半正定（最小特征值 ≥ −1e-10）；极分解；标号清理的小算例；约束 ARAP 在立方体上应近似恒等。
- 集成测试（ctest 标签 `models`，Release 构建运行）：三个模型的端到端运行，核对 spec 中的验收数值（I-SPAR 14 个面片、24 个角点；TAILSITTER 旋转约 45°；误差 < 1e-3；翻转四面体为 0）。
- CI：每次推送时两个平台只跑构建和单元测试（几分钟）。三个模型的集成测试在本地完整跑一遍要约 71 分钟，私有仓库下按 GitHub 计费（macOS 分钟 10 倍）成本过高，因此改为在 Actions 页面手动触发（`workflow_dispatch`）。

## Risks / Trade-offs

- [不用 CHOLMOD，直接分解太慢（已证实：10 万未知数单次 23 秒）] → 大问题改用 IC-CG 非精确求解；统计报告记录各部分耗时（旋转、装配、求解、线搜索）。
- [CAD 模型起点已接近 polycube，而早期阶段（ε 大、α 小）E1 几乎不区分方向，β 项又惩罚已有的 90° 棱，前几个阶段误差会先上升] → 属于论文调度本身的行为，靠后续 α 增大恢复；在实验文档中记录各模型的误差曲线。
- [TAILSITTER 很薄（8 / 87），ARAP 加 ℓ1 可能把它压扁或扭曲] → 在集成测试里观察畸变分布，必要时调 β；面积约束本身防止整体收缩。
- [TAILSITTER 的 0.5 台阶只有一排三角形高，可能产生大量小面片或停滞] → 依靠 β 和度 1/2 面片清理；结果作为后续是否需要"台阶塌缩"的依据，记录到统计报告的角点数中。
- [没有细长三角形塌缩，barrier 可能卡住] → 检测并记录；输入网格最小角 ≥13°，预计很少触发；真触发时作为单独的 change 处理。
- [最终映射可能出现翻转四面体（论文也没有加约束）] → 统计并报告；spec 要求 I-SPAR、CLEVIS 为 0，不满足时优先调整 ARAP 迭代次数和初值，再考虑加入防翻转项。
- [TAILSITTER 未达到原验收标准（已接受的已知限制）] → 默认参数下 ℓ1 误差停在约 0.003（20 个阶段，429 次迭代），最终映射解缠后仍剩 1 个翻转四面体（解缠前 131 个）。经用户确认，TAILSITTER 单独放宽为 d < 5e-3、翻转数 ≤ 四面体总数的 0.01%；I-SPAR、CLEVIS 维持 1e-3 和 0。后续可选方向：凹角孔洞附近局部加密、带单射约束的最终映射能量、或先对台阶和小孔做几何简化。
- [跨平台浮点差异累积] → spec 只要求跨平台满足阈值且面片数一致，不要求逐位一致。
- [libigl 与 Eigen 版本耦合] → 一律使用 libigl 配方中的 Eigen，并锁定 libigl 的 tag。
- [TetGen 在 -Y（保持边界）模式下，靠近边界的单元质量有限] → 报告最小二面角；单元质量差主要影响 ARAP 的条件数，可以通过质量参数调整。

## Migration Plan

全新工程，没有迁移问题。回滚只需删除新增目录。
