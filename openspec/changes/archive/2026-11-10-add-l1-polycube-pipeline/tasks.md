## 5. 能量项（spec: polycube-deformation；design D4）

- [x] 5.1 实现 polycube 误差指标 d（按面积归一化）；验证：未变形的 I-SPAR 上 d < 1e-6，TAILSITTER 上 d > 0.05

- [x] 5.3 实现 Eδ（按体积加权归一化的 ARAP），梯度为 GᵀGX − Gᵀpolar，Hessian 为常矩阵 GᵀG；验证：刚体变换下能量为 0，有限差分梯度检查通过
- [x] 5.4 实现 Eη（β 复杂度项，滞后 A(e_ij) 权重，Gauss-Newton Hessian）；验证：有限差分梯度检查（固定权重下），平面网格上能量为 0
- [x] 5.5 实现 Ee（直角或平坦特征边项，从文件读取边集），未提供时不起作用；验证：梯度检查，以及权重为 0 时总能量不变
